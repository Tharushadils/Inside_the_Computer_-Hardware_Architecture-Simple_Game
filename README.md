# 🖥️ PC Builder Game

A simple interactive PC Building Game where players can build their own computer by selecting different PC components.

The game is designed to make learning about computer hardware more fun and interactive.

[Play ](https://tharushadils.github.io/Inside_the_Computer_-Hardware_Architecture-Simple_Game/)





---

## 🎮 About the Game

**PC Builder Game** allows players to create a custom PC by choosing components such as:

- 🧠 CPU
- 🎮 GPU
- 💾 RAM
- 💿 Storage
- 🔌 Power Supply
- 🖥️ Motherboard
- 🖥️ PC Case
- ❄️ CPU Cooler

Players can compare their selected components and build a complete PC setup.

---

## ✨ Features

- 🖥️ Build a custom PC
- 🧩 Select different PC components
- 💰 View component prices
- 📊 Calculate the total build cost
- ⚡ Check component compatibility
- 🎯 Interactive game-based experience
- 🏆 Build the best PC within a budget
